# Frontend web Angular + Tailwind Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir en `web/` el directorio público de Bailoteca: listado filtrable y paginado de academias, detalle por slug, y despliegue en Vercel.

**Architecture:** SPA Angular 22 standalone (zoneless por defecto), Tailwind v4, `HttpClient` y signals. La URL es la fuente de verdad del listado (`?comuna=&style=&q=&page=`); rutas lazy para listado y detalle. Sin NgRx, sin SSR, sin acceso a base de datos.

**Tech Stack:** Angular 22.2, TypeScript 6, Tailwind CSS 4.1 (`@tailwindcss/postcss`), RxJS 7.8, Vitest 5, Vercel.

**Spec:** `docs/superpowers/specs/2026-11-09-web-design.md`

## Global Constraints

- Angular **22**, componentes **standalone**, `ChangeDetectionStrategy.OnPush` en todos los componentes, signals para estado local.
- **Tailwind CSS v4** CSS-first (`@import 'tailwindcss'`); sin `tailwind.config.js`.
- La URL de la API se inyecta con el token `API_BASE_URL`; **ningún componente** la importa ni la hardcodea.
- UI en **español de Chile**. Copy y errores exactos donde este plan los fija.
- No se filtra por `status` en el cliente. `closed` → badge "Cerrada"; `unknown` → "Sin verificar" solo en detalle.
- No se muestran `confidence`, `evidence`, `source_url` ni `source_urls`.
- Búsqueda: debounce de **300 ms**, mínimo **2 caracteres**, cancelación con `switchMap`.
- `page_size` fijo en **20** (`PAGE_SIZE`).
- Comandos reales del proyecto: `npm test -- --watch=false`, `npm run build`. `API_BASE_URL` es obligatoria para `npm run build`.
- No se toca `api/`, `shared/`, `parser/` ni `supabase/`; el frontend solo consume la API.

## Review Focus

1. **URL inválida o compartida** (`q` de 1 carácter, `style` con mayúsculas/espacios, `page=0`): se normaliza sin mandar un 422 a la API y sin romper back/forward.
2. **Página fuera de rango** (`page=999` con 3 páginas): redirige una sola vez a la última página; no hay loop de navegación.
3. **Academia con campos nulos** (`description: null`, `styles[].name: null`, `locations: []`, `links: []`): la tarjeta y el detalle renderizan sin excepciones.
4. **API caída, 429 o error de red**: se muestra un mensaje accionable con "Reintentar", nunca una pantalla en blanco.
5. **Deep link directo** (`/academias/slug` recargado) y slug inexistente: la SPA sirve `index.html` y el detalle muestra el estado 404 con vuelta al listado.
