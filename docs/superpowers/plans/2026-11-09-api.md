# API pública de Bailoteca — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implementar la API FastAPI de solo lectura de Bailoteca, con filtros, paginación, rate limit por IP y tests, reusando `bailoteca-shared`.

**Architecture:** FastAPI monta routers de `health` y `academies`; los filtros se resuelven en SQL dentro de `bailoteca-shared`, y la API solo valida parámetros y serializa con los DTOs compartidos. `slowapi` aplica un límite por IP en memoria; el pool de psycopg se crea de forma perezosa.

**Tech Stack:** Python 3.12+, FastAPI, Uvicorn, slowapi, psycopg 3 + psycopg_pool, pydantic-settings, pytest, Supabase Postgres.

**Spec:** `docs/superpowers/specs/2026-11-09-api-design.md`

## Global Constraints

- Python `>=3.12`.
- La API usa solo `DATABASE_URL_READONLY`; nunca la llave de escritura.
- No agregar Redis, Upstash ni otro servicio externo.
- Rate limit en memoria con `slowapi`; en Vercel es aproximado por instancia.
- No versionar `.env` ni secretos.
- Mensajes de error al cliente en español y sin stack traces.
- `list_published` debe conservar exactamente su salida actual.
- Instalación local: `pip install -e shared -e "api[dev]"`.
- Tests de API sin base de datos real; los de integración son opcionales.

## Review Focus

- **Filtros vacíos desde Angular** (`?comuna=&style=&q=`): deben tratarse como ausentes, no como 422 ni como búsqueda literal. Test en Task 3.
- **Comodines de `LIKE` en `q`** (`%`, `_`): deben buscar literalmente, no ampliar el resultado. Test en Task 1.
- **Base de datos ausente o caída**: debe responder 503, nunca 500 ni una lista vacía silenciosa. Test en Task 3.
- **IP detrás del proxy**: el límite debe usar el primer `X-Forwarded-For`; confiar en ese header solo detrás de Vercel. Test en Task 5.
- **RLS y rol read-only**: si faltan políticas, la API devuelve listas vacías. La migración de Task 6 las crea y la verificación manual contra Supabase es obligatoria.
